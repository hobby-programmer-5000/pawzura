# Product brief — hobby-programmer-5000

Original product direction supplied by hobby-programmer-5000 on 2026-11-02 (Asia/Seoul).

- A randomly designed, original SD character walks above the Windows taskbar and across extended displays.
- Open models hosted on Hugging Face generate the character; document all model usage and licensing.
- The companion jumps toward an unlisted app/site close button, bites it, shows a temporary fading crack, and closes the target.
- Allow Spotify, WhatsApp, VS Code, Docker, PowerShell, Ollama, common browsers, Codex, Claude, Antigravity and startup applications by default.
- Provide a tray icon to hide/remove the companion, edit program/site allowlists, change language, configure Windows startup and generate/change characters.
- Register browsers independently; initially permit built-in home/new-tab pages, allow explicit additional sites.
- Support Windows 10/11 and Python 3.12+, both source execution and an executable build.
- Create a uniquely named, initially private repository owned by hobby-programmer-5000.
- Attribute product ownership to hobby-programmer-5000 and AI implementation assistance to ChatGPT via Codex, including Git history where GitHub supports it.
- License original app code under MIT; preserve individual language, library and model licenses in THIRD-PARTY-NOTICES.md.

Implementation decisions and limitations are documented in README, docs/MODELS.md and docs/BROWSERS.md. These requirements originate with the user; implementation and explanatory documents are AI-assisted.
