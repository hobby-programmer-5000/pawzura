# Licensing

The [character rights notice](../../CHARACTER-POLICY.md) records that use is not an ownership transfer or separate authorization for a third party's exclusive trademark/design registration. It adds no MIT restrictions. See [provenance and limits](CHARACTER-RIGHTS.md).

Pawzura's original code is MIT-licensed. The binding English text is [LICENSE](../../LICENSE). Third-party languages, libraries, build tools and models keep their own terms: see [the full notices](THIRD-PARTY-NOTICES.md) and original texts under `licenses/`.

## Code and artwork are separate

The [official artwork policy and designation register](ASSET-LICENSING.md) reserves CC BY-NC-SA 4.0 for future, individually identified official art. **No assets are currently designated.** It does not restrict existing MIT material, default/random/Qwen vector variants, example prompts or independent user-generated images. Earlier commercial permissions remain. Read the asset guide before adding or reusing official art; model terms still apply separately.

The [Korean counterpart](../ko/LICENSE.md) includes an explanatory translation of the MIT text. It is not a replacement license. Original upstream legal documents are preserved verbatim; the project supplies bilingual explanations instead of altering their legal wording.
