# 0.6.0

Download **Pawzura-0.6.0-windows-x64.exe** for a single-file launch, or extract the full **Pawzura-0.6.0-windows-x64.zip**. Quit the previous app before upgrading. Each format uses the same local settings and application lock. A second launch reports the active instance. Storage failures receive their own message.

The standalone EXE expands support files temporarily. Extension staging and optional artwork workers use the bundled resources. **About → Open license notices** opens the included original texts. Matching application source, Qt/PySide/Shiboken source archives and rebuilding instructions are available with the release. [Usage, source and rebuilding](SINGLE-EXE.md).
