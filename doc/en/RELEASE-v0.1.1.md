# Pawzura 0.1.1 preview

- Short English-default README with a separate Korean version and topic guides under `doc/en` and `doc/ko`.
- Desktop defaults to English; General → Language → 한국어 → Save settings applies Korean immediately. Existing saved language choices are preserved.
- Browser connection now uses Browser, Port and Connection code fields, with a live Connect and test check and actionable messages.
- Sample values are clearly fake and cannot be used for a real connection. Old 0.1.0 JSON can populate the form through an optional importer.
- Opening the HTML file directly shows a preview explanation; install the extension and open Extension options to connect.
- Both languages, original legal notices and updated extensions are included in the portable ZIP.

Extract the full ZIP and run Pawzura/Pawzura.exe. Source users can run run.bat. The guardian stays off and preview stays on for new installations. See [getting started](GETTING_STARTED.md), [browser setup](BROWSERS.md) and [validation](VALIDATION.md).

Model choices, animation and existing preview limitations remain as documented. Original app code is MIT; dependencies and optional models keep their own licenses.
