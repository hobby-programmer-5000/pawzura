# 0.7.0

**Control browser tabs independently of application windows.** In **General**, keep **Enable focus guardian** checked, clear **Enable application control**, and click **Save settings**. In **Browsers**, turn on **Website control** and **Apply website allowlist to this browser** for a connected browser. Keep preview on while checking your rules. [Browser extension setup](BROWSERS.md).

Turning off application control stops application-window monitoring and cancels pending window closes. Existing settings keep application control checked on upgrade. The preference applies across allowlist profiles.

Download the standalone Windows EXE or extract the full Windows ZIP. Quit Pawzura before upgrading. [Downloads and usage](SINGLE-EXE.md).
