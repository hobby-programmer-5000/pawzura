# 0.4.1 — 브라우저 설정 페이지와 사용 안내

작은 개선판으로 **브라우저 → 브라우저 내부 설정 페이지** 칸을 추가했습니다. 브라우저를 선택하면 Chrome의 `chrome://settings`, Firefox의 `about:preferences` 등 알려진 설정 주소를 표시합니다. **이 브라우저의 설정 페이지 허용**은 신규·기존 설정 모두 기본으로 켜집니다. 브라우저·프로필별로 바꾸고 **설정 저장**하면 적용합니다. 하위 설정·검색 쿼리·fragment도 포함하며 일반 웹사이트는 별도 사이트 목록을 사용합니다. [주소 목록·사용법](BROWSERS.md#브라우저-내부-설정-페이지).

브리지가 허용 목록·프로필·감시 모드 변경을 확인하면 대기 중인 탭 닫기 승인을 취소합니다. 기존 새 탭·확장 설치 페이지 예외도 유지합니다. 이 업데이트는 기존 확장으로 동작하며 설정 페이지 옵션을 위해 확장을 다시 설치할 필요는 없습니다.

README 상단에 미리보기 사용 권장과 프로그램·제어할 브라우저 허용 목록을 완성·검증하기 전까지 해제 자제 안내를 넣었습니다. 해제 시 저장하지 않은 작업이 손실될 수 있다는 위험·책임 안내도 강조했습니다. 3D 시작 안내에는 그림 아래의 별도 준비 버튼 위치와 마지막 **이 캐릭터 사용 → 설정 저장** 순서를 명시했습니다. 선택형 3D는 계속 실험 기능이며 모델 라이선스·외형 품질 한계를 따릅니다.

## 업데이트와 검사

**Pawzura-0.4.1-windows-x64.zip**과 **SHA256SUMS-0.4.1.txt**를 받으세요. SHA-256을 확인하고 새 폴더에 ZIP 전체를 푼 뒤 이전 앱을 직접 종료하고 `_internal`과 함께 있는 `Pawzura/Pawzura.exe`를 실행합니다. 개인 목록·프로필·캐릭터는 로컬에 유지하며 업데이트가 감시나 사이트 제어를 켜지는 않습니다. 알려진 설정 페이지는 기본 허용하므로 원치 않으면 해당 체크를 끄고 저장하세요. 서명되지 않아 SmartScreen이 뜰 수 있습니다.

소스 검사에는 Python 회귀 198개·확장 19개와 합성 설정을 쓰는 언어/테마/크기별 브라우저 화면 16개가 포함됩니다. 배포 전에는 실제 EXE·내장 소스/버전·깨끗한 기본 설정·원본 고지·개인정보 제외·ZIP 무결성·체크섬을 추가 확인하고 Python 3.12/3.14/3.15 Windows CI를 검사합니다. 새 Windows 11 하드웨어/모델 검사나 개인 브라우저 프로필 전체 E2E를 주장하는 결과는 아닙니다. [검증 범위](VALIDATION.md).
