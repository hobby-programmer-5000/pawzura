# 0.1.7 프리뷰 — 설명으로 생성하고 직접 꾸미기

캐릭터 탭에서 한글·영문 자유 설명을 최대 2,000자까지 입력합니다. 몸·포인트·눈 색, 귀, 눈 표정, 얼굴 무늬, 장식, 꼬리, 날개를 직접 고를 수도 있습니다. 직접 고른 옵션은 Qwen 결과보다 우선합니다. 옵션 적용은 모델 없이 사용할 수 있고, 미리보기 확인 후 설정 저장으로 적용합니다. 이전 외형 복원·기본 외형 초기화도 유지합니다.

공식 Hugging Face의 Qwen2.5 0.5B·1.5B Q4_K_M을 로컬 Ollama로 선택 사용합니다. 상세 설명은 1.5B를 권장하며 앱이 모델을 동봉하거나 몰래 내려받지 않습니다. 선택한 모델의 다운로드 명령을 화면에 표시하고 Apache-2.0 원문·제작 기록을 문서화했습니다. 설명은 앱이 설정·외형 이력·로그에 저장하지 않으며 로컬 Ollama에만 보냅니다.

자체 벡터 도형을 조합하는 방식이므로 임의의 그림·의상·머리카락은 지원하지 않습니다. 실제 모델 예시에서도 일부 요청을 놓쳤으므로 정확해야 할 부분은 수동 옵션으로 지정하세요. [입력 예시·지원 옵션·모델 설치](MODELS.md)와 [검증 기록](VALIDATION.md)을 참고하세요.

영문·한글 설치 가이드와 앱 도우미에서 확장 관리 화면의 개발자 모드 스위치를 Ctrl+Shift+I 개발자 도구와 구분했습니다. 확장 폴더를 불러온 뒤 연결 페이지를 열도록 안내합니다.

기존 트레이 앱을 종료하고 ZIP 전체를 새 폴더에 풀어 그 안의 Pawzura.exe를 실행하세요. 기존 개인정보 설정은 로컬에만 유지하고 배포물 사이트 기본값은 비어 있습니다. 0.1.6의 오버레이 보호도 포함합니다.
