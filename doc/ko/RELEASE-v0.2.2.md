# 0.2.2 — 로컬 검사 응답 잘림 수정

긴 한국어 설명을 기존의 판정·요약 결합 요청으로 처리할 때 600토큰 응답 한도를 소진해 JSON이 끝나지 않고 막연한 로컬 검사 실패 오류가 날 수 있었습니다. 안전성·독창성 판정과 길이를 제한한 영어 요약을 분리하고 승인된 짧은 ASCII 설명은 그대로 유지합니다. 응답 잘림·형식 오류·모델 누락·연결·시간 초과·메모리·서비스 실패별로 검사 단계·모델과 다음 조치를 표시합니다. 부분 JSON을 임의 복구하거나 실패한 검사를 우회하지 않습니다.

문맥과 응답 범위를 명시해 긴 입력을 개선했지만 작은 모델은 세부 특징을 놓칠 수 있습니다. 기존 모델 라이선스·진행 표시·그림/감시 보호 규칙은 유지합니다. 새 모델·라이브러리는 필요 없으며 새 ZIP의 EXE로 재실행하면 설치한 모델·실행환경을 재사용합니다.
