# 0.7.0

**프로그램 창과 별개로 브라우저 탭만 제어할 수 있습니다.** **일반**에서 **집중 지킴이 켜기**는 체크한 채 **프로그램 제어 켜기**를 해제하고 **설정 저장**을 누르세요. 확장을 연결한 뒤 **브라우저**에서 **사이트 제어**와 **이 브라우저의 사이트 허용 목록 적용**을 켜세요. 허용 목록을 확인하는 동안에는 미리보기를 켜 두세요. [브라우저 확장 설치·연결](BROWSERS.md).

프로그램 제어를 끄면 프로그램 창 감시가 멈추고, 대기 중인 창 닫기 요청이 취소됩니다. 기존 설정으로 업데이트하면 프로그램 제어가 체크된 상태로 열립니다. 이 설정은 모든 허용 목록 프로필에 적용됩니다.

Windows 단일 EXE를 내려받거나 Windows ZIP 전체를 압축 해제하세요. 업데이트 전에 기존 Pawzura를 종료하세요. [다운로드와 사용법](SINGLE-EXE.md).
