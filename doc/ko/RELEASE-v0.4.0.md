# 0.4.0 — 방향별 모션과 캐릭터 재사용

생성한 캐릭터를 보관해 재사용하고, 필요 없는 버전과 미사용 파일을 삭제하며, 승인한 그림에서 실험적인 방향별 3D 클립을 준비할 수 있습니다. 설정에서 걷기 방향도 선택합니다. 기존 도형 캐릭터와 편집 가능한 2D 움직임도 계속 사용할 수 있습니다.

## 새 기능 사용

- **설정 → 일반 → 걷기 방향 → 왼쪽/오른쪽 → 설정 저장**으로 기본 방향을 정합니다. 배율이 다른 모니터를 넘거나 깨물기에서 돌아온 뒤에도 선택한 방향을 유지합니다.
- **설정 → 캐릭터 → 캐릭터 저장… / 저장한 캐릭터…**에서 이름을 붙이고 미리 본 뒤 재생성 없이 복원합니다. 승인한 그림과 준비한 모션은 적용 전에도 자동 보관합니다. 원본·검증한 모션·준비 캐시는 로컬에 보관하고 Git·배포에서 제외합니다. [보관함과 백업](CHARACTER-LIBRARY.md).
- **저장한 캐릭터… → 삭제…**에서 예상 확보 용량을 확인하고 영구 삭제합니다. **다시 쓰지 않는 파일도 함께 삭제**를 켜면 미사용 PNG·모션·확인된 완료 캐시도 정리하고, 끄면 항목만 삭제합니다. 현재/적용 대기 버전은 삭제를 막으며 다른 저장본과 이전 외형 이력이 쓰는 파일을 보호합니다. 알 수 없거나 진행 중인 캐시·모델 다운로드는 유지합니다. 모든 고아 파일을 검색하는 기능은 아닙니다.
- **창작 그림 만들기…**에서 모델 조건을 확인하고 **3D 모션 준비 · 8 GB · 포즈 보조**를 선택합니다. 복원·CPU 관절 추정·프레임 저장을 순차 실행합니다. 만들어진 로컬 묶음으로 옆 걷기·정면 멈춤·방향 전환·손 흔들기·점프·기쁨·깨물기를 재생하며 모델을 계속 실행하지 않습니다. [정확한 준비 방법·예시·한계](3D-MOTION.md).

3D 경로는 MIT TripoSR 코드·가중치와 Apache-2.0 ViTPose를 쓰며 라이브러리와 원본 그림 모델의 개별 조건도 적용됩니다. 별도 그림 실행환경 준비와 최소 8 GB VRAM의 NVIDIA CUDA GPU가 필요합니다. 더 작은 메모리 기준은 그림 생성·2D 움직임에 대한 안내입니다. ZIP에 가중치나 생성 캐릭터를 넣지 않습니다. 다운로드 전 [모델 고지](THIRD-PARTY-NOTICES.md)를 확인하세요.

## 품질과 검증 범위

관찰된 몸통 뒤로 젖힘을 포즈 보조 리깅에서 수정했으며, 리깅·모션만 바뀌면 호환되는 장면을 재사용합니다. 여전히 실험 기능입니다. 경계가 흐려지거나 관절·의상이 뒤틀리고 발이 미끄러지며 추정한 옆·뒷모습이 원본과 다를 수 있습니다. 전문 학습형 뼈대 생성이나 기본 도형 캐릭터보다 좋은 결과를 보장하지 않습니다. 결과가 나쁘면 원본을 유지하세요.

Windows 10 소스 검사에는 Python 회귀 187개·확장 19개·선택형 관절 수학 검사 3개·번역별 Qt 화면 검사와 실제 8 GB 테스트 캐릭터 생성·모션 준비가 포함됩니다. [검증](VALIDATION.md)과 3D 안내에 범위를 구분했습니다. 배포 전에는 최종 EXE 실행·내장 소스/버전·개인정보 제외·라이선스·체크섬도 확인해야 합니다. 이 검사로 새 Windows 11 하드웨어/모델 검사나 개인 브라우저 프로필 전체 E2E를 주장하지 않습니다.

## 업데이트

**Pawzura-0.4.0-windows-x64.zip** 전체를 받고 **SHA256SUMS-0.4.0.txt**와 SHA-256을 확인한 뒤 새 폴더에 압축을 푸세요. 이전 Pawzura는 직접 종료하고 새 `Pawzura/Pawzura.exe`를 실행하며 `_internal`을 옆에 유지합니다. 개인 설정·캐릭터는 PC에 남습니다. 서명되지 않은 빌드라 SmartScreen이 뜰 수 있습니다. 브라우저 탭 제어는 별도 확장 설치가 필요하고 AI 생성에는 Ollama 실행과 충분한 가용 메모리가 필요합니다.
