# 0.1.5 프리뷰 — 앱 안에서 확장 설치 안내

- **브라우저 → 확장 설치·연결…**을 추가합니다. 공개 확장 파일만 고정된 로컬 폴더에 준비하고 경로를 복사하며, 선택한 브라우저의 확장 관리 화면을 열어 남은 클릭을 안내합니다.
- Chromium 브라우저에서는 **연결 화면 열고 연결 요청**이 브라우저·포트·언어를 자동 입력한 옵션 페이지를 열고 승인 요청을 시작합니다. Pawzura의 ‘예’는 직접 선택합니다. 코드·JSON 복사가 필요 없습니다.
- 설정·트레이에 전체 **사이트 제어 ON/OFF**를 추가합니다. 즉시 적용하며 프로그램 감시와 사이트 목록은 유지합니다. 새 설치는 OFF이며 업그레이드는 기존 사이트 제어 선택을 유지합니다. 새 확장은 주소를 읽기 전에 상태를 확인하고 OFF일 때 주소 조회를 건너뜁니다.
- 최근 확장 연결 상태를 표시합니다. 설치·연결만으로 사이트 제어를 자동으로 켜지 않습니다.
- 앱 안에서 영문·한글 설치 단계를 보여주고 양쪽 README에 확장 필수를 강조합니다. 개발자 모드를 켜야 설치 버튼이 보인다는 점도 안내합니다.
- Chromium 개발용 공개 ID와 앱 데이터의 고정 확장 폴더를 사용합니다. 다른 ID의 예전 확장이 있다면 제거한 뒤 새 항목을 불러오세요. 사이트 목록은 로컬에 유지합니다. Firefox 옵션 페이지도 별도로 선언하며, 임시 설치 방식이므로 Chromium보다 직접 해야 할 단계가 많습니다.

기존 앱을 종료하고 새 ZIP 전체를 새 폴더에 압축 해제한 뒤 새 EXE의 도우미를 사용하세요. 브라우저에서 설치를 직접 승인해야 하며 무인·스토어 설치는 아닙니다. 관리 정책이나 브라우저 프로필을 수정하지 않습니다. 개인 설정·연결 정보는 압축 파일에 넣지 않습니다.
