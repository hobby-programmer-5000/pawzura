# 0.3.0 — 그림 손발 움직임과 반응

그림의 팔/손·발을 따로 움직이며 걷기·인사·점프·환호 자세를 사용합니다. 커서를 올리면 걷기를 멈추고 인사하며, 클릭할 때마다 인사/점프/환호 순서로 반응합니다. 더블 클릭이나 우클릭은 설정을 엽니다. 가끔 멈추어 인사하는 동작도 추가했습니다. 감시 기능의 깨물기가 우선하며 기존 종료 보호 장치를 유지합니다.

새 그림 준비에 선택형 Apache-2.0 ViTPose CPU 관절 도우미(가중치 약 350 MB)와 SciPy(BSD-3-Clause)를 추가했습니다. 생성 시 수정 가능한 네 영역을 제안하며 기본 예시도 손발이 보이도록 바꿨습니다. 기존 그림은 다시 생성할 필요가 없습니다. **캐릭터 → 그림 손발 움직임 설정… → 도우미 준비 → 관절 자동 추정 → 움직임 설정 사용 → 설정 저장**을 누르세요. 도우미 없이 직접 조정할 수도 있습니다. 준비는 별도 실행환경을 재사용하며 처음 설치할 때는 350 MB보다 많은 런타임 다운로드가 필요합니다.

2D 그림 조각 애니메이션이며 걷는 동안 계속 모델을 실행하지 않습니다. 잘못된 관절·가려진 손발·소매 경계는 직접 조정해야 할 수 있습니다. 원본 PNG는 유지하며 손발 움직임을 해제하면 그림 전체 흔들림으로 돌아갑니다. 편집기에 네 자세 미리보기와 번역된 진행·오류 안내가 있습니다. [움직임 조작·수정](ARTWORK-MOTION.md), [모델·라이선스](CREATIVE-ART.md), [검증 범위](VALIDATION.md)를 참고하세요.

0.2.2의 긴 설명 검사 오류 수정도 포함합니다. 새 ZIP 전체를 새 폴더에 풀고 기존 Pawzura를 직접 종료한 뒤 새 EXE를 실행하세요. 기존 로컬 설정·그림은 재사용하며 개인 목록·생성 그림은 배포하지 않습니다.
