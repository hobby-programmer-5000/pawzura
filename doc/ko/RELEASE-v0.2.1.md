# 0.2.1 — 보이는 그림 생성 진행 상황

창작 그림 창에 실제 생성 단계 수·현재 단계·전체/단계 경과 시간·마지막 진행 보고 이후 시간을 표시하는 고정 영역을 추가했습니다. 로딩·검사는 임의 비율 대신 대기형으로 표시합니다. 60초 동안 진행 보고가 없으면 안내하되 멈춤으로 단정하지 않습니다. 설치 단계와 완료한 모델 그룹 수도 보여줍니다. 작업 중 닫기를 눌러도 대기 메시지가 현재 단계를 가리지 않습니다. 성공·실패 시 시간을 멈추고 실패하면 기존 캐릭터를 유지합니다.

[진행 안내](CREATIVE-ART.md#진행-상황-확인) · [검증](VALIDATION.md). 모델 생성 방식·라이선스·콘텐츠 검사·개인정보 제외·감시 동작은 유지합니다. 취소나 확정적인 완료 예상 시간을 추가하지는 않았습니다.
