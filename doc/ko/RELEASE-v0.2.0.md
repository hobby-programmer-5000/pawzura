# 0.2.0 — 고정 도형을 넘어서는 창작 그림

**캐릭터 → 창작 그림 만들기…**는 별도의 선택형 이미지 생성 흐름입니다. 독창적인 실루엣·머리카락·의상·재질을 설명하면 기존 도형 특징을 고르는 대신 SD 1.5·SDXL이 실제 그림을 생성합니다. 가벼운 Qwen/수동 도형 모드도 유지하며 큰 Qwen은 같은 외형 틀의 해석 모델임을 명확히 표시합니다.

1. Ollama 설치·실행 후 새 그림 창에서 NVIDIA CUDA 2/4/6/8 GB 기준을 고르세요.
2. **선택 모델의 원본 라이선스를 읽고** 확인란을 체크하세요. 앱 코드는 MIT이며 그림 가중치는 제한 조건이 있는 별도 OpenRAIL입니다. 가중치를 배포본에 넣거나 OSI 승인 오픈소스로 표현하지 않습니다.
3. **실행환경·선택 모델 준비**를 누르세요. 대용량 다운로드와 추가 디스크·RAM이 필요합니다. 격리된 Python 3.12 그림 환경은 본 앱의 Python과 별개이며 포터블 EXE 사용자도 이용할 수 있습니다.
4. 독창적인 설명으로 생성하고 결과를 확인하세요. 로컬 요청·분류·비전 검사를 모두 통과해야 합니다. 미리보기의 입을 클릭해 깨물기 위치를 조정할 수 있습니다.
5. **이 캐릭터 사용 → 설정 저장**을 누르세요. 승인된 PNG는 재실행·이력에서 유지되며 전체 그림의 흔들림·반전·점프·깨물기를 사용합니다. 누락·손상 시 도형으로 대체합니다. 도형 옵션으로 그림을 편집할 수는 없습니다.

모델별 역할·라이선스, 메모리 기준, 준비와 오류 해결은 [창작 그림 안내](CREATIVE-ART.md)를 보세요. 클라우드 추론 없이 설명은 현재 창에서만 유지합니다. 개인 설정·그림·실행환경·가중치는 배포에서 제외합니다.

**한계:** NVIDIA 전용이며 메모리 기준이 실행 보장은 아닙니다. VRAM이 크다고 예쁜 결과를 보장하지 않습니다. 설명 반영·배경 제거가 불완전하며 관절별 AI 걷기·눈깜빡임 모델은 아닙니다. 안전·독창성 검사에는 누락·오차단이 있을 수 있고 법적 권리 검증이 아닙니다. 사용·공개 전 결과를 직접 확인하세요. GPU·실기기·사용자 브라우저 E2E 검증 범위는 [검증 문서](VALIDATION.md)를 보세요.
