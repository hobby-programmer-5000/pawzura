# 검증 기록

검증일: 2026-11-02 (Asia/Seoul). 지원 목표와 실제 확인한 환경을 구분합니다.

## 0.1.3 앱 보호와 자동 연결

로컬에서 **Python 42개·확장 18개** 검사가 통과했습니다. 예전 설정의 Codex/ChatGPT 별칭, 일반 창 닫기 경계의 브라우저 제외, TAB 표식 위치, 마지막 탭 대체와 실패 시 유지, 일회용 연결·origin 일치·승인·거절·만료를 검사했습니다.

새 임시 프로필에 실제 headless Chromium 확장을 설치해 코드 없는 연결, 옵션 탭 보호, 미허용 탭만 제거, 허용 탭 유지, 마지막 미허용 탭 뒤 빈 탭과 동일한 창 ID 유지를 확인했습니다. 앱 승인·애니메이션 이벤트는 테스트가 직접 처리하며 배포 GUI 확인창 클릭을 자동 검증했다는 뜻은 아닙니다. 사용자 프로필과 사용자 설정은 사용하지 않았습니다.

영어·한국어 자동 연결 화면을 캡처해 검토했고 TAB 표식 렌더링도 통과했습니다. 0.1.3 포터블 EXE 빌드와 offscreen 렌더링 검사의 정상 종료 코드 0을 확인했습니다.

## 0.1.2 주소 규칙 검사

로컬에서 **Python 33개·확장 14개** 검사가 통과했습니다. 도메인·HTTP/HTTPS·경로 경계·쿼리 조건·한글·기존 와일드카드·잘못된 경로·한국어 줄 번호와 실제 HTTP 브리지의 경로 규칙 적용을 포함합니다. 오류 신고에 있던 주소 7개의 형식도 모두 검증했습니다. 문서는 **자체 Markdown 33개·주제별 언어쌍 12개**를 검사합니다. 해당 사이트의 로그인 리디렉션이나 모든 링크를 자동으로 허용한다는 뜻은 아닙니다.

## 0.1.1 변경 검증 범위

로컬에서 **Python 23개**, **확장·연결 폼 14개**, **자체 Markdown 31개·주제별 언어쌍 11개와 상대 링크** 검사가 통과했습니다. 영어 기본값·한국어 저장·즉시 갱신 신호·코드만 복사·입력 검증·예시 거절·이전 JSON 가져오기·연결 상태·파일 미리보기를 확인했습니다. 명령은 [빌드 안내](BUILD.md)에 있습니다. 아래 결과는 0.1.0 기준선입니다.

별도 headless Chrome 프로필에서 실제 파일 미리보기 화면을 캡처해 배치를 검토했습니다. 0.1.1 포터블 EXE 빌드와 offscreen smoke-check의 정상 종료 코드 0을 확인했습니다. 사용자 프로필에 실제 확장을 설치하거나 사이트를 닫는 전체 동작 검증을 뜻하지는 않습니다.

## 발견하여 보정한 환경 문제

- Conda의 Python/Qt DLL 조합에서 QtCore import가 실패했습니다. 소스 실행 안내는 일반 CPython 전용 가상환경을 기본으로 합니다.
- PyInstaller가 서로 다른 Python/Qt/Shiboken 휠의 MSVC DLL을 포함하면, Windows가 먼저 로드한 구버전 런타임 때문에 QtCore import가 실패할 수 있습니다. 빌드 스크립트는 포함된 원본 Microsoft DLL 중 파일 버전이 가장 최신인 것을 동일 이름의 모든 배포 위치에 일관되게 복사합니다. Microsoft DLL 자체를 패치하지 않습니다.
- Qt offscreen 플러그인은 Windows 시스템 글꼴을 자동으로 찾지 못해 검사 전용 경로에서 시스템 Segoe UI와 맑은 고딕을 명시적으로 불러옵니다. 글꼴 파일은 재배포하지 않습니다.
- frozen EXE의 검사 종료 시 Qt 객체 정리 순서 문제를 발견하여, 검사 창과 타이머를 명시적으로 정리한 뒤 종료하도록 수정하고 정상 종료를 확인했습니다.
- Windows의 venv 실행기 PID와 실제 GUI Python PID가 달라질 수 있어 native probe는 자식 프로세스가 보고한 실제 PID로 대상을 검증합니다.
- 자동화 도구의 실제 창 스크린샷 캡처가 타임아웃되어, 시각 검토는 앱 자체 Qt 렌더링 캡처를 사용했습니다. 사용자 트레이 클릭부터 종료까지 전체 UI 조작을 자동 검증했다고 주장하지 않습니다.

## 별도 검증이 필요한 범위

- Windows 11 실기기, Windows 10 1809 최소 버전, ARM64, 원격 데스크톱 세션.
- 로컬에서는 Python 3.14.7, GitHub의 Windows runner에서는 Python 3.12/3.14/3.15를 검사했습니다. 이는 Windows 11 실기기·모든 CPython 패치 버전의 확인을 대신하지 않습니다.
- 실제 Chrome/Edge/Firefox 각 버전에 확장을 설치한 탐색·탭 닫기 E2E. 현재 자동 검사는 실제 HTTP 브리지와 확장 API mock을 각각 검증합니다. 사용자의 브라우저 설정이나 설치된 확장은 변경하지 않았습니다.
- Firefox 영구 설치를 위한 Mozilla 서명과 각 스토어 배포.
- 커스텀 창 프레임의 정확한 X 위치, 브라우저 실제 탭 X 위치, 관리자 권한 창의 닫기 거절, 전체 화면 앱과 가상 데스크톱.

기본 릴리스는 동작 검증 범위를 명시한 **0.1.0 preview**입니다. 집중 지킴이는 처음에 OFF, 미리보기 ON입니다. 앱 종료나 확장 제거로 우회할 수 있어 보안 통제 도구로 취급하지 않습니다.
