# 로컬 설정과 배포 개인정보

Pawzura는 사용자 허용 목록과 연결 코드를 `%LOCALAPPDATA%/Pawzura/settings.json`에 저장합니다. 앱 시작 시 이 파일을 읽으므로 업그레이드 후에도 이전 입력이 다시 보입니다. 화면에 표시되는 로컬 설정은 소스의 기본값이나 배포용 예시 목록과 별개입니다.

저장소 예시는 일반적인 도메인을 사용합니다. 사용자 허용 목록·브라우저 프로필·연결 자격 정보를 소스·스크린샷·테스트·로그·배포 ZIP에 추가하면 안 됩니다. 화면 검사는 임시 설정과 별도 브라우저 프로필만 사용합니다.

빌드는 ZIP 생성 전에 출력 폴더를 검사하여 로컬 설정·연결 파일·브라우저 프로필·이름을 바꾼 설정 내보내기를 거절합니다. `python scripts/check_distribution.py 압축해제한_배포폴더`로 같은 검사를 실행할 수 있습니다. 구조 검사는 수동으로 추가한 이미지 등의 내용 검토를 대신하지 않습니다.

0.1.3 릴리스와 태그·첨부 파일은 철회했습니다. 이번 개인정보 변경에서 대체 릴리스를 게시하지 않습니다. 소스 버전은 미배포 개발 버전입니다. 사용자 PC의 설정은 유지하며 GitHub 릴리스 삭제가 개인 PC의 환경설정 삭제를 뜻하지는 않습니다.
