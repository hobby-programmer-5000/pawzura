# 로컬 설정과 배포 개인정보

0.1.5 설치 도우미는 `%LOCALAPPDATA%/Pawzura/extensions/`에 공개 확장 파일 6개만 준비합니다. 환경설정을 복사하거나 브라우저 프로필을 읽고 고치지 않으며 연결 링크에도 토큰을 넣지 않습니다. 새 확장은 사이트 제어 OFF일 때 주소 조회 없이 인증된 상태만 확인합니다. 프로그램 감시는 독립적으로 유지됩니다. 예전 확장도 앱에서 비활성 결정을 받지만 주소 조회 전 확인까지 적용하려면 앱·확장을 함께 업데이트하세요.

Pawzura는 사용자 허용 목록과 연결 코드를 `%LOCALAPPDATA%/Pawzura/settings.json`에 저장합니다. 앱 시작 시 이 파일을 읽으므로 업그레이드 후에도 이전 입력이 다시 보입니다. 화면에 표시되는 로컬 설정은 소스의 기본값이나 배포용 예시 목록과 별개입니다.

저장소 예시는 일반적인 도메인을 사용합니다. 사용자 허용 목록·브라우저 프로필·연결 자격 정보를 소스·스크린샷·테스트·로그·배포 ZIP에 추가하면 안 됩니다. 화면 검사는 임시 설정과 별도 브라우저 프로필만 사용합니다.

0.1.7부터 캐릭터 설명은 현재 설정 창에만 보관하고 별도 설치한 로컬 Ollama로만 보냅니다. Pawzura는 설명을 설정·외형 이력·로그에 저장하지 않습니다. 설명 지우기로 비울 수 있으며, 설정을 트레이로 닫으면 앱 종료나 창 재생성 전까지 입력이 유지됩니다. 검증된 외형 값과 지원 모델 식별자만 저장합니다. Ollama 자체 동작은 별도로 확인하세요.

빌드는 ZIP 생성 전에 출력 폴더를 검사하여 로컬 설정·연결 파일·브라우저 프로필·이름을 바꾼 설정 내보내기를 거절합니다. `python scripts/check_distribution.py 압축해제한_배포폴더`로 같은 검사를 실행할 수 있습니다. 구조 검사는 수동으로 추가한 이미지 등의 내용 검토를 대신하지 않습니다.

이전 0.1.3 릴리스와 태그·첨부 파일은 철회했습니다. 관리자 요청으로 새 소스 커밋에서 기능을 추가해 [0.1.3을 재빌드](RELEASE-v0.1.3.md)하고 새 ZIP·체크섬으로 배포합니다. 전체 압축 파일을 다시 받아 철회된 빌드를 교체하세요. 사용자 PC의 설정은 유지하며 GitHub 릴리스 삭제가 개인 PC의 환경설정 삭제를 뜻하지는 않습니다. 기존 목록은 로컬 Default 프로필로 옮기며 새 릴리스에 그 내용을 넣지 않습니다.
