# Pawzura 0.1.0 preview

고유 벡터 SD 캐릭터, 작업표시줄 위 산책, 다중 모니터 이동, 점프·깨물기·사라지는 균열과 선택적으로 켜는 집중 지킴이를 제공한 첫 버전입니다.

Windows ZIP 전체를 풀고 `Pawzura/Pawzura.exe`를 실행합니다. `_internal`과 라이선스 폴더를 함께 보관해야 합니다. Python 없이 EXE를 실행하거나 소스로 실행·빌드할 수 있습니다.

처음에는 감시 OFF·미리보기 ON입니다. 일반 창 닫기 요청을 사용하고 강제 종료하지 않습니다. 사이트 감시는 브라우저별 확장 설치·연결이 필요합니다. Qwen 기반 외형 생성은 별도 Ollama 설치가 필요한 선택 기능입니다.

Python 20개·확장 6개 검사, 제어된 Win32 테스트 창 닫기, 실제 Qwen 생성, Windows 10/CPython 3.14.7의 소스·EXE 렌더링과 정상 종료를 확인했습니다. 이후 Python 3.12·3.14·3.15 CI도 통과했습니다.

Windows 11 실기기와 실제 확장 전체 동작은 별도 확인이 필요합니다. 탐색 후 탭을 닫으며, 탭 X 좌표 대신 창 X 또는 바탕화면 위치를 사용합니다. Firefox 영구 설치는 서명이 필요합니다. 자체 코드 MIT, 개별 의존성·모델 라이선스는 유지합니다.

이전 버전 기록입니다. 최신 사용법은 [처음 사용하기](GETTING_STARTED.md), [브라우저 연결](BROWSERS.md)을 참고하세요.
