# Pawzura 0.1.2 preview

사이트 허용 목록에 `github.com/my-account`, `example.com/ko?viewMode=svod`처럼 경로와 쿼리가 있는 주소를 그대로 넣을 수 있습니다. 이전에는 해당 주소가 한 줄이라도 있으면 편집한 목록 전체를 저장하지 못했습니다.

도메인은 사이트 전체, 경로는 해당 구역과 하위 경로를 허용합니다. 쿼리 조건은 지정한 값이 같아야 합니다. 생략한 프로토콜은 HTTPS로 처리하며 HTTP·HTTPS 완전한 주소를 각각 지원합니다. 프로토콜 접두어만 넣으면 불완전한 주소이며 모든 사이트 허용 규칙이 아닙니다. fragment는 무시합니다.

잘못된 줄은 영어·한국어 줄 번호 오류로 안내하고 저장 후 정규화된 주소를 표시합니다. 기존 와일드카드 저장 형식도 읽습니다. 위장 호스트·비슷한 이름의 다른 경로·모호하게 인코딩된 경로 구분자는 계속 거절합니다.

ZIP 전체를 풀고 이전 앱을 종료한 뒤 새 Pawzura.exe를 실행하세요. 기존 0.1.1 브라우저 확장과 연결 방식은 같습니다. [브라우저 예시](BROWSERS.md)와 [검증 기록](VALIDATION.md)을 참고하세요. 자체 코드는 MIT이며 동봉 구성요소의 개별 조건은 유지합니다.
