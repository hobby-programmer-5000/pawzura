# 그림 캐릭터의 손발 움직임

소스 업데이트: [실험용 8GB 포즈 추정 보조 3D 움직임](3D-MOTION.md)이 승인한 그림을 실제 앱에 연결합니다. 아래 이전 릴리스·실험 설명은 당시 범위를 유지합니다.

생성한 그림에서 양팔/손·양발의 네 영역을 나누어 움직입니다. 걸을 때 번갈아 움직이고 인사·점프·환호는 서로 다른 자세를 사용합니다. 기존에 승인된 그림도 다시 생성하지 않고 설정할 수 있습니다.

## 새 그림 만들기

[창작 그림 만들기](CREATIVE-ART.md)에서 업그레이드 후 준비를 다시 실행하고 생성하세요. 준비 과정에 CPU 관절 도우미가 추가되며 생성할 때 손발 영역을 자동 제안합니다. 기본 예시는 양손·부츠 신은 양발이 보이고 팔이 몸통에서 조금 떨어진 서 있는 캐릭터를 요청합니다. 이런 구도가 관절 추정에 유리합니다. 적용 전에 움직이는 미리보기를 확인하세요.

추정이 불확실해도 검사를 통과한 그림은 버리지 않습니다. 손발 움직임 정보가 없으면 완료 메시지로 알려줍니다. **그림 손발 움직임 설정…**에서 설정하세요. 대체 표시의 그림 전체 흔들림은 손발을 따로 움직이는 기능과 다릅니다.

## 기존 그림의 움직임 추가·수정

1. **설정 → 캐릭터 → 그림 손발 움직임 설정…**을 여세요. 그림 캐릭터를 선택했을 때 활성화됩니다. 그림 생성 창에서도 같은 버튼으로 승인된 미리보기를 수정할 수 있습니다.
2. 선택 사항: **CPU 움직임 도우미 준비 (약 350 MB)**를 한 번 실행한 뒤 **관절 자동 추정**을 누르세요. 준비에는 인터넷이 필요합니다. 추정은 Ollama·GPU VRAM 대신 로컬 CPU를 사용하며 모듈·모델 로딩에 수 초 이상 걸릴 수 있습니다. 단계·경과 시간·마지막 보고 이후 시간을 표시합니다. 준비는 별도 그림 실행환경을 재사용하고 패키지도 설치·갱신할 수 있으므로 처음 설치하는 환경에서는 도우미 가중치보다 훨씬 많이 다운로드합니다. 직접 편집만 한다면 도우미 다운로드가 필요 없습니다.
3. 네 부위를 각각 선택하세요. **그림 왼쪽·오른쪽은 화면의 방향**이며 캐릭터 신체 기준 좌우가 아닙니다. 색 윤곽은 움직일 픽셀, 동그라미는 회전 관절입니다.
4. 윤곽 안을 끌면 이동, 네모 모서리는 크기 변경, 동그라미는 관절 이동입니다. 빈 곳을 끌면 해당 부위를 사각형으로 다시 그립니다. 머리·몸통·다른 손발을 포함하지 않도록 감싸세요. 팔 관절은 팔꿈치/윗부분, 발 관절은 부츠 윗부분 가까이에 두세요.
5. 실시간 미리보기에서 **걷기·인사·점프·환호**를 확인하세요. 잘못된 영역이나 심한 경계를 조정하세요. 어려운 그림은 소매 전체보다 손만 작게 선택하는 편이 나을 수 있습니다.
6. **손발을 각각 움직이기** 선택 → **움직임 설정 사용** → 본창의 **설정 저장**을 누르세요. 새 그림 생성 창에서는 본창 저장 전에 **이 캐릭터 사용**도 눌러야 합니다. 취소하면 이전 선택을 유지합니다.

**제안 영역 초기화**는 편집기를 열 때의 영역으로 돌아가며, 영역이 없었다면 일반적인 시작 사각형을 사용합니다. 추론을 다시 실행하지 않습니다. 손발 움직임 선택을 해제하고 저장하면 그림 전체 흔들림으로 돌아갑니다. 원본 PNG는 유지되며 움직임을 바꿔도 그림을 다시 그리지 않습니다. 캐릭터 기록에는 검증한 움직임 설정도 함께 보관됩니다. [복구·기록 안내](PROFILES-AND-RECOVERY.md).

## 캐릭터와 상호작용

| 조작 | 반응 |
| --- | --- |
| 커서 올리기 | 걷기를 멈추고 커서를 향해 인사하며 반짝임 표시 |
| 왼쪽 클릭 | 클릭할 때마다 인사 → 점프 → 환호 순서로 반응 |
| 걷는 동안 기다리기 | 가끔 멈추어 인사 |
| 더블 클릭 또는 우클릭 | 설정 열기 |

이 반응으로 프로그램을 끄거나 대기 중인 감시 동작을 대체하지 않습니다. 감시 기능의 깨물기가 우선입니다. 화면 복구는 이전 반응과 대기 중 애니메이션을 취소합니다. 평소 걷기·상호작용은 Qt만 사용하며 그림·관절·영상 추론을 계속 실행하지 않습니다. 설정 후 추가 VRAM도 필요하지 않습니다.

## 도우미·개인정보·한계

선택 도우미는 [usyd-community/vitpose-base-simple](https://huggingface.co/usyd-community/vitpose-base-simple)이며 [카탈로그](../../art_runtime/catalog.json)에 리비전을 고정했습니다. 약 350 MB, **Apache-2.0**입니다. 전처리에 **SciPy (BSD-3-Clause)**를 사용합니다. 원문 라이선스는 [타사 고지](THIRD-PARTY-NOTICES.md)에 있습니다. Pawzura는 MIT를 유지합니다. 가중치는 앱에 포함하지 않고 별도로 다운로드합니다.

이 기능은 수정 가능한 **2D 그림 조각 애니메이션**입니다. 도우미는 사람 형태의 관절을 추정하므로 동물·작거나 가려진 팔다리·특이한 실루엣·손에 든 물건은 잘못 추정하거나 추정하지 못할 수 있습니다. 없는 손가락·가려진 신체·새 시점을 만들어내지 않습니다. 소매를 움직이면 틈이 드러나며 단순 가장자리 혼합으로 경계·색 늘어짐·픽셀 잘림이 남을 수 있습니다. 영역·관절을 조정하거나 손만 작게 선택하고, 필요하면 기능을 해제하세요. 이 버전은 네 영역이 모두 유효해야 활성화됩니다. AI 걷기 영상이나 모든 관절이 움직이는 3D 캐릭터는 아닙니다.

로컬 캐릭터에는 범위를 검증한 윤곽·관절 좌표만 저장합니다. 승인된 픽셀은 stdin을 통해 로컬 도우미로 전달하며 경로·프롬프트를 내보내지 않습니다. 기존 그림 안전 검사는 유지합니다. [개인정보](PRIVACY.md)와 [검증 범위](VALIDATION.md)를 참고하세요.
