# Pawzura 0.1.1 preview

- 영어 기본의 짧은 README와 별도 한국어 버전, `doc/en`·`doc/ko`의 주제별 안내를 제공합니다.
- 앱 기본 언어는 영어입니다. General → Language → 한국어 → Save settings를 저장하면 한국어가 즉시 적용됩니다. 기존에 저장한 언어는 유지합니다.
- 브라우저·포트·연결 코드 입력 폼과 실제 연결 확인, 원인을 알려 주는 상태 메시지를 제공합니다.
- 예시는 가짜임을 표시하고 실제 연결에 사용하지 못하도록 합니다. 0.1.0의 JSON은 선택적으로 가져와 입력 칸에 적용할 수 있습니다.
- HTML 파일을 직접 열면 미리보기 안내를 표시합니다. 실제 연결은 확장 설치 후 확장 프로그램 옵션에서 합니다.
- 포터블 ZIP에 양언어 문서, 라이선스 원문과 새 확장을 포함합니다.

ZIP 전체를 풀고 Pawzura/Pawzura.exe를 실행하세요. 소스 사용자는 run.bat를 실행할 수 있습니다. 새 설치의 감시 OFF·미리보기 ON은 유지합니다. [처음 사용하기](GETTING_STARTED.md), [브라우저 연결](BROWSERS.md), [검증 범위](VALIDATION.md)를 참고하세요.

모델·애니메이션과 기존 preview 제한은 문서에 그대로 구분했습니다. 자체 코드 MIT, 의존성과 선택 모델의 개별 라이선스는 유지합니다.
