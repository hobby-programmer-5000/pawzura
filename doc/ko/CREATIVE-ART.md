# GPU로 독창적인 그림 만들기

**캐릭터 → 창작 그림 만들기…**는 같은 도형의 귀·꼬리·장식을 고르는 대신 실제 그림을 생성합니다. 독창적인 실루엣·의상·머리카락·재질·표현 방식을 설명하세요. 가벼운 **Qwen으로 생성**과 직접 외형 옵션은 그림 실행환경 없이 계속 사용할 수 있습니다.

## 다운로드 전 확인

- Windows 10/11 x64와 지원되는 **NVIDIA CUDA GPU**가 필요한 선택 기능입니다. 현재 AMD·Intel 그래픽과 CPU 전용 그림 생성은 지원하지 않습니다. 기본 앱은 이 기능 없이도 동작합니다.
- [Ollama](https://ollama.com/)를 설치하고 실행하세요. 그림 실행환경은 별도이며 Windows Ollama는 그림을 그리지 않고 **로컬 검사**에 사용합니다.
- **디스크 여유 25 GB**, **시스템 RAM 최소 16 GB**(SDXL은 32 GB 권장), 충분한 가용 VRAM이 필요합니다. 총용량과 남은 용량은 다릅니다. 필요하면 다른 GPU·모델 작업을 직접 종료하세요.
- 최초 준비에는 수십 분이 걸릴 수 있습니다. 실행환경 약 4 GB, 검사용 모델 약 3.5 GB와 선택한 그림 모델을 내려받습니다. 설치 후 크기와 캐시는 더 커질 수 있습니다. 작업이 끝날 때까지 창을 열어 두세요.
- **고급 모델 사용 전 선택 모델의 원본 라이선스를 확인하세요.** Pawzura 코드는 MIT지만 SD 1.5·SDXL 가중치는 제한 조건이 있는 별도의 OpenRAIL 라이선스이며 MIT·Apache 또는 OSI 승인 오픈소스가 아닙니다. 앱은 가중치를 포함하거나 재라이선스하지 않습니다. 선택형 설치기는 별도 조건을 가진 NVIDIA 구성요소 등 타사 실행환경도 내려받습니다. [고지](THIRD-PARTY-NOTICES.md)를 참고하세요.

## 메모리 기준 선택

아래는 시작 설정이며 **실행·품질 보장이 아닙니다**. 하드웨어·가용 메모리·드라이버·시스템 RAM에 따라 달라집니다. 높은 기준은 같은 도형 옵션의 제한을 적용하는 대신 그림 모델·해상도를 바꿉니다.

| GPU VRAM 기준 | 그림 모델 | 해상도 | CPU 분산 | 그림 가중치 | 원본 조건 |
| --- | --- | --- | --- | --- | --- |
| 2 GB | [SD 1.5](https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5) | 384 × 384 | 순차, 매우 느림 | 약 2.3 GB | [CreativeML OpenRAIL-M](https://github.com/CompVis/stable-diffusion/blob/main/LICENSE) |
| 4 GB | SD 1.5 | 512 × 512 | 모델 단위 | 약 2.3 GB | SD 1.5와 동일 |
| 6 GB | [SDXL base 1.0](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0) | 768 × 768 | 순차, 매우 느림 | 약 7 GB | [CreativeML Open RAIL++-M](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/blob/462165984030d82259a11f4367a4eed129e94a7b/LICENSE.md) |
| 8 GB | SDXL base 1.0 | 1024 × 1024 | 모델 단위 | 약 7 GB | SDXL과 동일 |

그림 모델은 한 장의 일러스트를 만듭니다. 몸·의상·머리카락의 고정 옵션 목록은 없지만 설명 반영·신체 표현·배경 제거가 완벽하지는 않습니다. VRAM이 크다고 더 예쁜 결과를 보장하지 않습니다. 긴 설명은 텍스트 인코더에서 뒤쪽 특징이 누락될 수 있으므로 핵심을 앞에 간결하게 적으세요.

## 준비와 생성

1. **캐릭터 → 창작 그림 만들기…**를 엽니다. **고급**에서도 열 수 있습니다.
2. VRAM 기준을 고르고 원본 라이선스 링크에서 이용 제한을 읽은 뒤 확인란을 선택하세요. 기준을 바꾸면 확인이 해제됩니다. 확인 상태는 현재 창에서만 유지됩니다.
3. **1. 실행환경·선택 모델 준비**를 누르세요. `%LOCALAPPDATA%\Pawzura\art-runtime`에 격리된 Python 3.12.14와 버전을 고정한 CUDA 패키지를 설치합니다. 전역 Python·PATH·관리자 권한·영구 PowerShell 실행 정책을 바꾸지 않습니다. 공식 uv 파일의 체크섬을 검증해 환경을 준비합니다. 실패 후나 그림 모델 계열을 바꿀 때 다시 준비하면 기존 캐시를 재사용합니다.
4. 선택 그림 모델, CPU NSFW 분류기, 배경 제거 모델과 아래 정확한 Ollama 검사 모델을 내려받습니다.

   ```powershell
   ollama pull hf.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF:Q4_K_M
   ollama pull qwen3-vl:2b
   ```

5. 독창적인 설명을 쓰거나 **예시 넣기**를 누르세요. 예: “초승달 모양의 유리·황동 몸, 청록색 곱슬머리, 자수 놓인 남색 망토, 구리 부츠와 떠 있는 등불을 지닌 작은 천문학자. 따뜻한 수채화와 잉크 표현, 친근한 표정, 전신.” 기존 캐릭터·프랜차이즈·로고를 지목하지 마세요. 금지 표현은 부정 지시에도 넣지 마세요.
6. **그림 생성**을 누르면 로컬 설명 판정 → 필요하면 간결한 영어 요약 → 그림 생성 → 이미지 분류·배경 제거 → 비전 검사 순서로 진행합니다. 노트북, 특히 순차 CPU 분산에서는 오래 걸릴 수 있습니다. 현재 작업이 끝난 뒤 창을 닫거나 앱을 종료하세요.
7. 결과 확인 → **이 캐릭터 사용** → 본창의 **설정 저장**을 누르면 적용됩니다. 오류가 나면 기존 외형을 유지하며, 재시도 실패 전의 결과도 계속 선택할 수 있습니다.

설명·그림은 클라우드 추론 서비스로 보내지 않습니다. 설치는 공식 패키지·모델 호스트에 접속하며 추론은 고정된 로컬 파일과 `127.0.0.1:11434`를 사용합니다. 설명은 현재 창에만 남으며 설정·명령 인자·앱 로그에 저장하지 않습니다. 별도 서비스인 Ollama에는 자체 동작이 있습니다. 승인된 PNG는 메타데이터를 제거한 뒤 `%LOCALAPPDATA%\Pawzura\artwork`에 내용 해시로 저장하며 모델이 지정한 임의 경로는 받지 않습니다. 이력에는 최대 20개 외형 참조가 남고 오래된 PNG를 자동 삭제하지는 않습니다.


## 진행 상황 확인

준비·생성 중에는 스크롤 영역 아래에 진행 상황이 계속 표시됩니다. 현재 단계, 전체 경과 시간, 현재 단계 시간, 마지막 진행 보고 이후 시간을 보여줍니다. 그림 생성은 실제 완료한 확산 단계 수(예: 12/30)를 표시하며 이 비율은 전체 작업이 아닌 현재 생성 단계의 비율입니다. 모델의 스케줄러에 따라 단계 수가 달라질 수 있습니다. 생성 뒤 이미지 변환·CPU 안전 검사·배경 제거·최종 비전 검사가 이어지므로 30/30이 최종 완료는 아닙니다.

라이브러리·모델 로딩과 로컬 검사는 신뢰할 수 있는 비율을 받지 못하므로 대기형 막대를 사용합니다. 설치는 도구·Python·PyTorch·라이브러리·라이선스 단계를 구분하며 모델 준비는 다운로드 바이트 대신 완료한 모델 그룹 수를 셉니다. 임의의 전체 완료 예상 시간은 만들지 않습니다. 60초간 진행 보고가 없으면 안내를 표시합니다. 로딩·CPU 분산·네트워크 전송·검사가 계속 진행 중일 수도 있으므로 이것만으로 멈춤을 확정할 수 없습니다. 새 보고가 오면 안내가 사라집니다. 작업 중 닫기를 눌러도 현재 단계와 수치는 유지됩니다.

완료·실패 시 시간 표시를 멈추고 완료/중단됨을 표시합니다. 기존 검사 제한 시간을 유지하며 그림 작업 프로세스 대기는 30분, 실행환경 설치와 각 Ollama 다운로드는 60분으로 제한합니다. 시간 초과 시 대기를 끝내고 기존 캐릭터를 유지합니다. 로컬 검사·설치 하위 작업은 백그라운드에서 끝날 수 있지만 실패 뒤 늦게 온 진행·결과는 적용하지 않습니다. 이번 변경은 취소나 검사 우회를 추가하지 않습니다. 진행 정보는 고정된 단계 코드·수치만 전달하며 백엔드 로그·설명·개인 경로·연결 정보는 표시하거나 저장하지 않습니다.

## 움직임과 복구

그림 전체의 흔들림·좌우 반전과 기존 점프·깨물기·균열 동작을 사용합니다. **관절별 걷기·눈깜빡임을 생성하는 AI 스프라이트 모델은 아닙니다.** 비전 모델이 추정한 입 위치에 깨물기 표시를 맞추므로 오차가 있을 수 있습니다. 생성 미리보기에서 입을 클릭해 십자 위치를 조정한 뒤 사용하세요. 기존 프로그램·브라우저 닫기 보호 규칙은 계속 적용됩니다.

도형 옵션으로 그림의 색이나 형태를 편집할 수는 없습니다. 다시 생성하거나 **임의 캐릭터**·**기본 외형으로 초기화**로 도형 모드에 돌아가세요. **이전 캐릭터로 변경**은 그림·도형 참조를 복원하고 **캐릭터 화면 복구**는 위치를 복구합니다. PNG가 없거나 손상되면 도형 대체 외형을 표시합니다. 그림을 다시 생성하거나 보관된 이력을 복원하세요. 설정 백업 시 artwork 폴더도 보관해야 하며 EXE만 복사하면 개인 외형은 옮겨지지 않습니다.

## 콘텐츠와 권리

NSFW 및 식별 가능한 기존 캐릭터·로고의 복제 요청은 금지합니다. 요청의 금지어 검사, 로컬 Qwen 설명 검사, 별도 CPU NSFW 분류기와 Qwen3-VL 그림 검사를 사용합니다. 검사 불가·잘못된 응답은 미검사 결과를 적용하지 않고 거부합니다. 누락이나 정상 요청의 오차단이 가능하며 **저작권 검증 또는 완벽한 안전 필터가 아닙니다.** 사용·공개 전에 결과를 직접 확인하세요. 모델 라이선스가 결과물의 독점권·상표 검증·타인 권리 비침해를 보장하지 않습니다. 모델 재배포 시 해당 조건을 유지해야 하며 앱의 MIT가 이를 대체하지 않습니다.

## 문제가 생기면

| 증상 | 다음 단계 |
| --- | --- |
| 준비·생성 버튼 비활성 | 라이선스를 읽고 선택 기준의 확인란을 체크하세요. |
| 실행환경 없음·준비 실패 | 인터넷·디스크 25 GB 여유·NVIDIA 드라이버·Ollama 설치를 확인하고 준비를 다시 누르세요. 캐시를 재사용합니다. |
| 검사 모델 없음 | 설명/그림 검사 단계와 정확한 모델을 표시합니다. 준비 버튼이나 표시된 `ollama pull` 명령을 이용하세요. |
| 검사 응답 잘림 | 모델 누락이 아닌 응답 한도 오류입니다. 판정·요약을 분리한 Pawzura 0.2.2 이상으로 업데이트하세요. 반복되면 주요 외형 특징을 남겨 설명을 줄이세요. |
| Ollama 연결 불가·검사 시간 초과 | Ollama를 실행하거나 다른 로컬 모델 작업이 끝나길 기다리고 메모리를 확보한 뒤 재시도하세요. 연결 오류 때문에 그림 환경을 재설치할 필요는 없습니다. |
| 검사 메모리·서비스·잘못된 응답 | 표시된 모델과 원인별 안내를 따르세요. 메모리 오류는 여유 확보, 서비스 오류는 Ollama 업데이트·정확한 이름 확인이 필요합니다. 잘리거나 잘못된 JSON은 거부하며 사용자가 JSON을 편집하지 않습니다. |
| CUDA 사용 불가 | NVIDIA 드라이버를 업데이트하세요. AMD·Intel·CPU는 지원하지 않습니다. 호환되지 않으면 도형 설계를 이용하세요. |
| 메모리 부족 | 다른 GPU 작업을 종료하고 8/6 GB 대신 4/2 GB로 내려 SD 1.5를 준비하세요. 시스템 RAM도 확보해야 하며 RAM 8 GB와 VRAM 8 GB를 혼동하지 마세요. |
| 배경 제거 실패·일부 누락 | 흰색 단색 배경·뚜렷한 실루엣·전신 캐릭터 하나를 요청하세요. 공중에 떠 있는 장식은 줄여서 다시 시도하세요. |
| 정상 요청 거부 | 기존 정체성·로고·선정적이거나 잔혹한 묘사·부정 지시의 금지어를 빼고 독창적인 특징을 더 명확히 적으세요. 실패한 검사를 우회하지 않습니다. |
| 실행환경 진단 필요 | 압축 해제한 Pawzura/소스 폴더에서 아래 PowerShell 명령을 실행하세요. `cuda: true`는 GPU가 보인다는 뜻이며 여유 메모리를 보장하지 않습니다. 설명은 전송하지 않습니다. |

```powershell
& "$env:LOCALAPPDATA\Pawzura\art-runtime\venv\Scripts\python.exe" art_runtime\runner.py check --tier 8 --cache "$env:LOCALAPPDATA\Pawzura\art-runtime\models"
```

고정 모델 revision은 [카탈로그](../../art_runtime/catalog.json)에 있습니다. 선택 실행환경의 패키지 라이선스 파일은 해당 환경에 유지됩니다. 실제 확인 환경과 GPU별 미검증 범위는 [검증 문서](VALIDATION.md)를 보세요. 8 GB 결과만으로 2/4/6 GB 실기기 검증을 추정하지 마세요.

설명 검사는 전체 입력에 대한 작은 판정만 반환합니다. 승인된 비 ASCII·긴 입력은 별도로 최대 512자의 영어로 요약하고 중복 정리 후 55단어로 제한합니다. 사용 가능한 짧은 ASCII 설명은 그대로 사용합니다. 한국어 기본 색상 번역은 힌트일 뿐 외형 제한 목록이 아닙니다. 작은 모델은 세부 특징을 누락·변경할 수 있으므로 정확한 표현이 중요하면 간결한 영어도 도움이 됩니다. 텍스트 검사 문맥 8,192토큰과 요약 응답 1,024토큰에는 실행 메모리가 필요합니다. 판정·요약·그림 검사 중 하나라도 실패하면 검사를 건너뛰지 않고 기존 캐릭터를 유지합니다.
