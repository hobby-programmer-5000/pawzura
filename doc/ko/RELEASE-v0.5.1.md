# 0.5.1 — 로컬 브라우저 주소

**브라우저**에서 사용하는 브라우저와 허용 목록 프로필을 선택하세요. 로컬 서버 하나를 허용하려면 `http://127.0.0.1:3000`처럼 포트까지 입력하고 **설정 저장**을 누르세요. HTTP와 HTTPS는 별도 규칙입니다. 포트를 생략한 주소는 HTTP가 80번, HTTPS가 443번을 사용합니다.

포트가 바뀌는 로컬 앱을 허용하려면 **하위 도메인 포함**을 끄고 `127.0.0.1`만 추가하세요. 선택한 브라우저와 프로필에서 이 IP의 모든 HTTP·HTTPS 포트를 허용합니다. [브라우저 허용 목록 안내](BROWSERS.md#일반-웹사이트).

Releases에서 **Pawzura-0.5.1-windows-x64.zip**과 SHA-256 체크섬을 받으세요. 이전 Pawzura를 종료하고 ZIP 전체를 새 폴더에 압축 해제한 뒤 `_internal`과 함께 있는 `Pawzura/Pawzura.exe`를 실행하세요. 설치한 브라우저 확장은 계속 사용할 수 있습니다. 미리보기 모드에서 갱신한 허용 목록을 확인하세요.
