# 0.1.8 프리뷰 — 하위 도메인 규칙 쉽게 추가하기

브라우저 탭에 주소 추가 입력란과 기본 OFF인 하위 도메인 포함 선택을 넣었습니다. console.example.com을 넣으면 해당 호스트를, example.com을 넣고 체크하면 example.com과 *.example.com을 함께 추가합니다. 생성한 규칙은 목록에 보이며 설정 저장을 눌러 적용합니다. 기존 규칙·감시 스위치·개인 로컬 설정은 유지합니다.

경로·쿼리·프로토콜·포트 조건도 유지합니다. console.example.com에서 부모·형제 사이트를 추측하지 않으며 위장 호스트는 계속 제외합니다. IP·localhost는 개별 주소로 추가합니다. 확장·인증 브리지는 기존 규칙 형식을 사용하며 새 권한이나 자동 전체 허용 규칙을 추가하지 않습니다. [예시](BROWSERS.md)와 [검증 기록](VALIDATION.md)을 참고하세요.

기존 트레이 앱을 종료하고 새 ZIP 전체를 풀어 그 안의 Pawzura.exe를 실행하세요. 깨끗한 기본값과 한영 안내, 최근 추가한 작은 앱 제작 규칙도 포함합니다. 이번 UI 변경에 모델·브라우저 확장의 추가 권한은 필요하지 않습니다.
