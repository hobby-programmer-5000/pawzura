# 업무·여가 프로필과 캐릭터 복구

0.1.5 이상의 전체 **사이트 제어** 스위치도 프로필 공통입니다. OFF로 두면 목록이나 프로그램 감시를 바꾸지 않고 프로그램만 제어하며 즉시 적용됩니다.

## 허용 목록을 따로 만들기

설정 상단의 **허용 목록 프로필**을 사용합니다. 각 프로필은 프로그램 허용 목록과 모든 브라우저의 사이트 목록·적용 여부를 함께 저장합니다. 브라우저 연결, 언어, 캐릭터, 감시·미리보기와 탐색된 시작프로그램은 공통입니다.

1. **Default**를 그대로 쓰거나 **이름 변경…**으로 **업무**라고 바꿉니다.
2. **프로그램**에서 업무용 프로그램을 입력합니다. **브라우저**에서 브라우저를 선택하고 `example.com/work/*`처럼 허용 주소를 입력합니다. 다른 브라우저도 설정합니다.
3. **설정 저장**을 눌러 목록을 적용·저장합니다.
4. **다른 이름으로 저장…**에서 **여가**를 입력하고 프로그램과 사이트를 바꿉니다. 예시는 `example.org/*`입니다. 새 프로필은 선택한 프로필을 복사해 시작합니다.
5. 다시 **설정 저장**을 누릅니다.

이후에는 **업무**나 **여가**를 선택하고 **설정 저장**을 누르면 전환됩니다. 선택·이름 변경·삭제는 설정의 편집본을 바꾸며 실제 감시에는 저장 후 적용됩니다. 다른 프로필을 선택해도 직전 프로필의 수정 내용은 편집본에 남습니다. 잘못된 입력은 전환·저장 전에 고쳐야 합니다. **삭제**는 확인 후 진행하며 마지막 프로필은 지울 수 없습니다. 이름은 중복 없는 1–64자이며 최대 32개를 지원합니다. 이번 버전에는 시간에 따른 자동 전환이나 가져오기·내보내기가 없습니다.

업그레이드하면 기존 적용 목록을 **Default**에 넣어 유지합니다. 이전 로컬 항목이 다시 보인다고 배포 예시에 포함된 것은 아닙니다. 프로필은 같은 [로컬 설정 파일](PRIVACY.md)에만 저장하며 릴리스 패키지에 넣지 않습니다.

시스템 창·알려진 브라우저 창·앱 자체는 계속 보호합니다. 탐색된 시작프로그램은 공통 예외이므로 두 프로필 모두에서 허용될 수 있습니다. 실제 닫기를 켜기 전에 **미리보기**로 목록을 확인하세요. 브라우저 변경은 다음 확장 검사부터 반영되며 이미 전송 중인 응답을 소급해 회수하는 기능은 아닙니다.

## 안 보이거나 깨진 캐릭터 복구

시계 근처 Pawzura 트레이 아이콘을 오른쪽 클릭 → **캐릭터 화면 복구**를 누릅니다. 아이콘이 없으면 Windows의 숨겨진 아이콘 화살표를 확인하세요. **캐릭터** 탭에도 같은 버튼이 있습니다.

복구는 즉시 실행됩니다. 진행 중인 깨물기를 대상을 닫지 않고 취소하고, 균열 창을 없앤 뒤 투명 캐릭터 창을 새로 만들어 저장된 외형으로 주 모니터의 작업표시줄 위에 온전히 표시합니다. 허용 목록·프로필·저장된 외형을 유지합니다. 저장하지 않은 외형 수정은 설정 편집본에 남으며 이 복구 버튼에는 적용하지 않습니다.

외형 자체를 되돌리려면 **캐릭터 → 기본 외형으로 초기화 → 설정 저장**을 누르세요. 프로그램·사이트 목록은 유지하고 연보라색 목도리 토끼로 돌아갑니다. **이전 캐릭터로 변경**은 로컬 외형 이력을 불러오는 별도 기능이며 적용하려면 저장해야 합니다.

모니터 추가·제거와 화면 영역 변경 시 진행 중인 점프를 취소하고 주 화면으로 복귀합니다. 매 프레임 투명 그리기 영역을 지운 뒤 다시 그립니다. 화면 밖 위치와 잔상 문제를 보완하지만 모든 GPU·배율·원격 데스크톱 문제를 해결했다고 검증한 것은 아닙니다. [검증 한계](VALIDATION.md)를 참고하세요.
