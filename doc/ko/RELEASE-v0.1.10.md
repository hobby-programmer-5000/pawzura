# 0.1.10 — 막히지 않는 모델 준비 안내

**캐릭터 → 명령 복사**를 선택 모델 바로 옆으로 옮기고 다운로드 용량·**모델 준비 안내** 버튼을 배치했습니다. PowerShell에 붙여넣기 → Enter → `success`까지 대기 → 다시 생성 순서로 진행합니다. 모델 오류에는 정확한 요청 모델과 전체 다운로드 명령을 표시합니다. 비슷한 이름의 설치 모델이나 다른 양자화로 자동 대체되지는 않습니다.

고급 탭에서도 안내를 열 수 있습니다. CPU/모름 0.5B, 2GB/CPU 1.5B, 4GB Qwen3 4B Q4_K_M, 6GB Qwen3 4B Q8_0, 8GB Qwen3 8B Q4_K_M 각각의 복사 가능한 명령·용량·실행/다운로드/재시도 순서를 넣었습니다. 시스템 RAM과 GPU VRAM의 차이, 기존 메모리·기기 검증 한계도 설명합니다. 안내를 열거나 명령을 복사해도 모델 설치·추론·설정 저장을 하지 않습니다.

한영 README와 [전체 준비 안내](ADVANCED-MODELS.md)에 모든 모델의 정확한 명령, `ollama list` 확인, 명령/모델 없음·다른 Ollama 호스트에 대한 대응을 넣었습니다. 모델 추론·라이선스·브라우저/프로그램 종료·개인 설정은 유지됩니다. 이전 트레이 앱을 종료하고 ZIP 전체를 풀어 **Pawzura.exe**를 실행하세요. 기존 확장에는 추가 권한이 필요 없습니다. [검증 기록](VALIDATION.md)을 참고하세요.
