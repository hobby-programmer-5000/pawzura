# Pawzura 0.1.3 preview

- 예전 허용 목록에서도 codex.exe를 허용하면 실제 실행 파일 ChatGPT.exe를 함께 보호합니다.
- 알려진 브라우저 창은 후보 검사와 최종 닫기 경계에서 프로그램 닫기 대상으로 삼지 않습니다.
- 브라우저 창 X 대신 제목 표시줄 아래 TAB 표식에 애니메이션을 표시합니다.
- 마지막 미허용 탭을 닫을 때는 같은 창에 about:blank를 먼저 만듭니다. 실패하면 탭을 그대로 두며 확장 자신의 옵션 페이지도 보호합니다.
- 확장에서 자동 연결을 누르고 데스크톱 앱에서 승인하면 됩니다. 코드 입력은 필요 없습니다. 요청은 1분 뒤 만료되고 요청한 확장 origin에 인증 정보를 한 번만 전달합니다.

이전 앱을 종료하고 ZIP 전체를 푼 뒤 새 Pawzura.exe를 실행하세요. extensions/chromium의 확장 또는 Firefox 부가 기능도 다시 로드하세요. 기존 연결 정보와 설정은 유지합니다. 주소 읽기와 탭 조작 권한을 위해 확장은 한 번 설치해야 합니다.

Python 42개·확장 18개 검사와 실제 별도 Chromium의 자동 연결·허용/미허용 탭·동일 창의 마지막 탭 유지 검사를 통과했습니다. [연결 안내](BROWSERS.md)와 [검증 범위](VALIDATION.md)를 참고하세요. 자체 코드 MIT와 개별 구성요소 라이선스는 유지합니다.
