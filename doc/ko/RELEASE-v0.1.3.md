# 0.1.3 프리뷰 — 재빌드 배포

철회했던 0.1.3 프리뷰를 새 소스 커밋과 ZIP·체크섬으로 교체합니다. 전체 ZIP을 다시 받으세요. 같은 버전 번호만으로 철회된 빌드와 구분할 수 없습니다. 이전 앱을 종료하고 새 폴더에 전체 압축을 푼 뒤 `Pawzura.exe`를 실행하세요. 동봉된 브라우저 확장도 업데이트·새로고침하세요. PC의 기존 로컬 설정은 **Default**로 옮겨 유지하며 배포 기본값에 넣지 않습니다.

- `example.com/*`는 해당 HTTPS 호스트의 모든 경로, `example.com/section/*`는 해당 구역을 허용합니다. 단순 도메인도 이미 모든 경로를 허용합니다. HTTP·HTTPS와 하위 도메인은 별도로 지정합니다.
- 프로그램·브라우저 허용 목록 프로필의 복사·이름 변경·삭제·활성 선택 저장을 추가합니다. [업무·여가 사용법](PROFILES-AND-RECOVERY.md)을 참고하세요.
- 트레이·캐릭터 탭의 즉시 **캐릭터 화면 복구**, **기본 외형으로 초기화 → 설정 저장**을 추가합니다. 복구는 취소한 깨물기로 대상을 닫지 않고 투명 창을 새로 만듭니다.
- 캐릭터 전체를 작업표시줄 위에 배치하고, 화면 변경 시 복귀하며, 투명 프레임을 지우고 다시 그립니다. 손상된 저장 외형도 보정합니다.
- Codex/ChatGPT 별칭, 브라우저 창 보호, 마지막 탭 뒤 창 유지와 코드 없는 승인 연결을 유지합니다.
- 패키징 시 로컬 설정·프로필 내보내기·브라우저 프로필 파일·연결 정보를 차단합니다. 예시는 일반 도메인만 씁니다.
- 영문·한글 캐릭터 권리 고지와 제작 이력을 포함합니다. 자체 소스는 MIT, 동봉 구성요소는 개별 라이선스를 유지합니다.

빌드·화면 캡처에 사용자 브라우저 프로필이나 사용자 허용 목록을 쓰지 않습니다. [개인정보](PRIVACY.md), [브라우저 예시](BROWSERS.md), [실제 검사와 남은 한계](VALIDATION.md)를 참고하세요. Windows 11 실기기와 모든 GPU·배율 조합을 검증한 것은 아니며 프리뷰 상태입니다.
