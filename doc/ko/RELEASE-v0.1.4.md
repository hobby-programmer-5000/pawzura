# 0.1.4 프리뷰 — 탭 동작과 창 닫기 표시 구분

기존 대체 좌표는 탭 균열을 화면 오른쪽 위에 표시해 브라우저 전체를 닫으려는 것처럼 보일 수 있었습니다. 활성·백그라운드 탭을 실제 해당 창이 아닌 현재 브라우저 창에 표시할 수도 있었습니다. 이 좌표 경로를 제거했습니다.

- 탭 이벤트는 캐릭터의 작업표시줄 근처에 별도로 만든 **탭 미리보기 ×** / **차단 탭 ×** 표식을 깨뭅니다. 실제 브라우저 탭 X가 아닌 별도 표식임을 명시합니다.
- 같은 차단 탭·주소는 티켓 만료 때 반복하지 않고 한 번만 미리보기로 보여줍니다. 미리보기는 탭을 닫지 않습니다. 주소 이동·설정 적용 시 다시 시연할 수 있습니다.
- 실제 닫기는 계속 확장에서 해당 탭에만 수행합니다. 알려진 브라우저 창은 일반 앱 닫기에서 제외하며 마지막 탭 대체·주소 재확인·허용 탭 보호를 유지합니다.
- 0.1.3의 업무·여가 프로필, 캐릭터 복구, 영문·한글 안내와 로컬 설정을 유지합니다. 개인 목록·연결 정보는 배포에 넣지 않습니다.

실행 중인 앱을 종료하고 새 ZIP 전체를 새 폴더에 푼 뒤 `Pawzura.exe`를 실행하세요. 동봉된 브라우저 확장도 새로고침하세요. [브라우저 동작](BROWSERS.md), [검증](VALIDATION.md), [개인정보](PRIVACY.md)를 참고하세요. 소스는 MIT, 동봉 구성요소는 개별 라이선스를 유지합니다.
