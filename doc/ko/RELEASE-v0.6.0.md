# 0.6.0

**Pawzura-0.6.0-windows-x64.exe**를 받으면 파일 하나로 실행할 수 있습니다. **Pawzura-0.6.0-windows-x64.zip**은 전체를 풀어 실행하세요. 업데이트 전에 기존 앱을 종료하세요. 각 형식은 같은 로컬 설정과 실행 잠금을 사용합니다. 두 번째 실행은 이미 실행 중이라고 안내하며 저장소 오류는 별도로 표시합니다.

단일 EXE는 지원 파일을 임시로 풉니다. 확장 설치와 선택형 그림 작업기는 포함된 리소스를 사용합니다. **정보 → 라이선스 문서 열기**에서 원문을 읽을 수 있습니다. 대응 앱 소스, Qt/PySide/Shiboken 원본 소스 압축 파일과 재빌드 지침을 릴리스에서 제공합니다. [사용법·소스·재빌드](SINGLE-EXE.md).
