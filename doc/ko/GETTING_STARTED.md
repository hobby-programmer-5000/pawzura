# 처음 사용하기

## 1. 앱 실행

[Releases](https://github.com/hobby-programmer-5000/pawzura/releases)에서 Windows ZIP을 내려받고, 마우스 오른쪽 버튼 → **모두 압축 풀기**를 선택하세요. 압축을 푼 `Pawzura` 폴더에서 **Pawzura.exe**를 더블 클릭하세요. `_internal`, `extensions`, `doc`, `licenses` 폴더는 EXE 옆에 함께 두세요. ZIP 안에서 바로 실행하지 마세요.

캐릭터만 사용하려면 Python·Ollama·모델 설치가 필요 없습니다. 소스로 실행하려면 일반 CPython을 설치하고 `run.bat`를 더블 클릭하세요. 자세한 내용은 [소스 실행 안내](BUILD.md)에 있습니다.

설정 창과 작업표시줄 위 캐릭터가 나타납니다. 처음에는 **감시 OFF·미리보기 ON**입니다.

## 2. 한국어로 변경

기본 언어는 **영어**입니다. **General → Language → 한국어 → Save settings**를 선택하세요. 저장하면 설정 창과 트레이 메뉴가 한국어로 바뀝니다. 영어로 돌아가려면 **일반 → 언어 → English → 설정 저장**을 선택하세요. 업그레이드할 때 기존에 저장한 언어는 유지합니다.

## 3. 창을 닫지 않고 체험

**일반 → 깨물기 애니메이션 미리보기**를 누르세요. 이 시연은 창을 닫지 않습니다. **캐릭터 → 임의 캐릭터 → 설정 저장**으로 모델 없이 캐릭터를 바꿀 수 있습니다. [Qwen 생성](MODELS.md)은 선택 기능입니다.

## 4. 허용 프로그램 설정

**프로그램**에서 **실행 파일 추가…** 또는 **열려 있는 프로그램 추가…**로 계속 열어 둘 앱을 추가하고 저장하세요. 창 제목 대신 `code.exe` 같은 실행 파일명을 사용합니다. 기본 허용 앱과 탐색한 시작프로그램은 이미 포함돼 있습니다. Windows 시스템 창과 Pawzura 자체는 보호합니다.

**일반**에서 **미리보기 모드**를 켜 둔 채 **집중 지킴이 켜기 → 설정 저장**을 선택하세요. 미허용 창에 애니메이션만 나타나고 실제로 닫히지는 않습니다. 허용 목록이 맞는지 확인한 다음 **미리보기 모드**를 해제하고 저장하면 일반 닫기 요청을 보냅니다. 저장 확인창은 건너뛰지 않습니다.

## 5. 브라우저 연결 — 선택 사항

데스크톱 앱만으로는 브라우저 주소를 검사할 수 없습니다. 브라우저마다 동봉된 확장을 설치하고 입력 폼으로 연결하세요. [Chrome/Edge 연결 순서와 예시](BROWSERS.md)를 따라 하세요. `options.html` 파일을 직접 여는 것은 화면 미리보기일 뿐, 확장 설치가 아닙니다.

## 자주 쓰는 조작

| 할 일 | 위치 |
| --- | --- |
| 설정 열기 | Windows 시계 옆 Pawzura 아이콘 클릭. 안 보이면 숨겨진 아이콘 화살표 확인 |
| 감시 중지 | 아이콘 우클릭 → 집중 지킴이 끄기 |
| 캐릭터만 숨기기 | 우클릭 → 캐릭터 숨기기 |
| 앱 완전 종료 | 우클릭 → 종료 |
| 로그인 시 실행 | 일반 → Windows 로그인 시 자동 실행 → 설정 저장 |
| 언어 변경 | 일반 → 언어 → 설정 저장 |

설정 창의 닫기 버튼은 트레이로 돌아갑니다. **캐릭터 숨기기**는 감시를 계속하고, **종료**는 앱 전체를 중지합니다.

## 문제가 생기면

- **DLL 파일 오류:** ZIP 전체를 풀고 `_internal`을 EXE 옆에 두세요.
- **창이 안 닫힘:** 집중 지킴이가 켜져 있고 미리보기가 해제됐는지 확인하세요. 사이트 감시는 브라우저 설정과 확장 연결도 필요합니다.
- **브라우저 연결 실패:** 앱을 켜 두고 현재 연결 코드를 다시 복사한 뒤 포트를 확인하세요. 확장 화면이 코드 거절·앱 연결 실패의 원인을 표시합니다.
- **이전 버전 실행 중:** 이전 버전의 트레이 메뉴에서 종료한 다음 새 EXE를 실행하세요.
- **Conda에서 Qt 오류:** [일반 CPython 설정](BUILD.md)을 사용하세요.

[검증 범위와 제한](VALIDATION.md)도 확인하세요. 설정 파일은 `%LOCALAPPDATA%\Pawzura\settings.json`에 있습니다.
