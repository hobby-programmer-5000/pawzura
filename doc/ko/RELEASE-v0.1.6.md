# 0.1.6 프리뷰 — 그래픽 오버레이 보호와 반복 미리보기 방지

- 도구·비활성·클릭 통과·자식 창과 시스템 메뉴가 없는 창을 프로그램 감시 대상에서 제외합니다.
- 편집 가능한 목록에 없어도 일반적인 그래픽 오버레이·드라이버 보조 프로세스와 WebView2 호스트를 보호하며 실제 닫기 경계에서도 차단합니다.
- 프로그램 미리보기는 대상 식별 정보가 바뀌거나 설정을 다시 적용하기 전까지 한 번만 표시합니다. 미리보기 콜백이 모드 변경 후 실제 닫기로 바뀌지도 않습니다.
- 비활성 도구 스타일의 균열·탭 표식 창을 캐릭터가 소유하고 재사용해 창 생성·제거를 줄입니다.
- 점프 후 현재 모니터의 바닥으로 돌아오며 깨무는 순간 취소·복구된 좌표를 덮어쓰지 않습니다.
- 0.1.5 설치 도우미·사이트 전체 스위치·업무·여가 프로필과 로컬 설정을 유지합니다. 개인 목록·원시 진단 정보는 동봉하지 않습니다.

이전 앱을 트레이에서 종료하고 새 ZIP 전체를 실행하세요. 사이트 설정은 로컬에 유지하며 확장 프로토콜·고정 ID는 그대로입니다. [오버레이 문제 해결](OVERLAYS-AND-PREVIEW.md), [실제 검증 범위](VALIDATION.md)를 참고하세요. 예전 감시 앱을 실행한 상태에서 신고된 깜빡임 전체를 재현한 것은 아니며 과거 프로세스 재시작을 확정하지 않습니다. 자체 코드는 MIT, 의존성은 각 라이선스를 유지합니다.
