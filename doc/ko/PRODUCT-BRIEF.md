# 제품 요구사항 — hobby-programmer-5000

2026-11-02 (Asia/Seoul)에 사용자가 제시한 원안입니다.

- 임의로 설계한 고유 SD 캐릭터가 Windows 작업표시줄 위와 확장 모니터를 넘나들며 걷습니다.
- Hugging Face의 오픈 모델로 외형을 생성하고 모델 사용·라이선스를 문서화합니다.
- 미허용 프로그램/사이트의 닫기 버튼 부근으로 점프해 깨물고, 균열을 표시하며 대상을 닫은 후 균열을 서서히 지웁니다.
- Spotify, WhatsApp, VS Code, Docker, PowerShell, Ollama, 주요 브라우저, Codex, Claude, Antigravity와 시작프로그램을 기본 허용합니다.
- 트레이에서 캐릭터 숨기기·종료, 프로그램/사이트 목록, 언어, 자동 실행, 캐릭터 생성·변경을 설정합니다.
- 브라우저별로 등록하며 처음에는 내장 시작/새 탭 페이지만 허용하고 다른 사이트를 추가할 수 있습니다.
- Windows 10/11, Python 3.12+, 소스 실행 및 EXE 빌드를 지원 대상으로 합니다.
- 고유한 이름의 private 저장소를 hobby-programmer-5000 계정에 만들고 기획자와 ChatGPT/Codex의 역할을 구분합니다.
- 자체 코드는 MIT, 언어·라이브러리·모델은 각자의 라이선스를 따르고 원문 고지를 보존합니다.
