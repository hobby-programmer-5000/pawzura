# 0.1.9 — 밝은 테마와 고급 로컬 설계 모델

**일반 → 화면 테마 → 라이트 (화이트) → 설정 저장**으로 흰색 설정 창을 선택합니다. 기본은 계속 다크입니다. 선택 즉시 미리 보이며 저장하면 유지되고, 캐릭터 미리보기·확장 설치 도우미에도 적용합니다. 브라우저 확장 자체 페이지의 외형은 별도입니다.

새 **고급** 탭에서 **VRAM 2·4·6·8GB 기준**을 직접 선택합니다. 기존 Qwen2.5 0.5B/1.5B에 공식 Apache-2.0 Qwen3 4B Q4_K_M(4GB 기준), 4B Q8_0(6GB), 8B Q4_K_M(8GB)을 추가합니다. 설명을 같은 벡터 특징으로 해석합니다. 이미지 생성 모델·GPU 자동 감지·큰 모델 자동 선택·몰래 다운로드하는 기능은 추가하지 않습니다. [준비·메모리·라이선스](ADVANCED-MODELS.md)를 참고하세요.

**AI 설계에는 실행 중인 Ollama, 선택한 모델 다운로드, 충분한 가용 RAM·VRAM이 필요합니다.** 장착 VRAM·파일 크기만으로 실행 가능성을 보장하지 않으며 GPU/CPU 배치는 Ollama가 정합니다. 기존 제한된 JSON 검사를 유지하고, 고급 모델은 비사고 모드로 생성 후 내립니다. 모델 없음·Ollama 연결 실패·메모리 부족은 한영 대응 방법을 표시하며 현재 캐릭터를 유지합니다.

README에서 SmartScreen 표시 가능성, 브라우저 탭 제어용 확장 필수 설치, 모델 준비 조건을 강조합니다. 이전 트레이 앱을 종료하고 ZIP 전체를 풀어 **Pawzura.exe**를 실행하세요. 설정은 로컬에서 이어 쓰며 개인 허용 목록이나 모델 가중치를 동봉하지 않습니다. 기존 확장에는 이번 데스크톱 변경을 위한 추가 권한이 필요 없습니다.

[검증 기록](VALIDATION.md)에서 자동·화면·배포물 검사와 실제 하드웨어 추론을 구분합니다. 신규 Qwen3 가중치를 받아 기기 벤치마크를 하지는 않았으며, 2·4·6·8GB는 검증된 최소 사양이 아닙니다. 기존 브라우저·기기 검증 한계도 유지합니다.
