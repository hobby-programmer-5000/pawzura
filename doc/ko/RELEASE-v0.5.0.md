# 0.5.0 — 캐릭터 고정과 드래그

작업을 방해하는 캐릭터를 옮기거나 고정할 수 있습니다.

- 캐릭터 우클릭 → **일반 → 현재 위치에 캐릭터 고정 → 설정 저장**으로 걷기를 멈춥니다.
- **마우스 왼쪽 버튼**을 누른 채 끌어서 놓으면 그 위치에 즉시 고정·로컬 저장합니다. 짧은 클릭의 인사·점프·환호와 우클릭·더블 클릭의 설정 열기는 유지합니다.
- 고정 체크를 해제하고 저장하면 선택한 방향으로 작업표시줄 위를 다시 걷습니다. 고정 여부·위치는 허용 목록 프로필 공통이며 재시작 후에도 복원합니다.

고정해도 집중 지킴이·사이트 제어 설정은 유지합니다. 깨물 때는 잠시 이동하고 고정 위치로 돌아옵니다. 드래그 시작 시 진행 중인 깨물기와 대기 중인 브라우저 승인을 취소하며 놓기 전에는 새 동작을 시작하지 않습니다. 이미 닫힌 대상은 되돌리지 못합니다. 마우스 캡처 해제·화면 구성 변경 시 드래그 상태를 안전하게 정리합니다. 저장·이동 위치는 음수 원점을 포함한 현재 모니터의 사용 가능 영역 안에 맞춥니다. **캐릭터 화면 복구**는 저장 위치를 지우고 고정 여부를 유지한 채 주 모니터 작업표시줄 위로 이동합니다. [사용법과 저장 실패 안내](PROFILES-AND-RECOVERY.md#캐릭터가-방해될-때-옮기기).

## 코드와 공식 그림

앱 코드와 기존 MIT 허가는 유지합니다. 새 [공식 그림 정책](ASSET-LICENSING.md)은 앞으로 명시적으로 지정할 공식 자산에만 CC BY-NC-SA 4.0을 선택합니다. **현재 지정 목록은 비어 있습니다.** 기존 기본·임의 생성·Qwen 도형 캐릭터, 예시 프롬프트와 독립적인 사용자 생성물을 자동으로 비상업 전용으로 바꾸지 않습니다. 제3자 모델·라이브러리는 각자의 조건을 유지합니다. 새 그림·모델·의존성은 추가하지 않았습니다.

## 업데이트와 검증

**Pawzura-0.5.0-windows-x64.zip**과 **SHA256SUMS-0.5.0.txt**를 받으세요. 체크섬을 확인하고 새 폴더에 ZIP 전체를 푼 뒤 이전 Pawzura를 종료하고 `_internal`과 함께 있는 `Pawzura/Pawzura.exe`를 실행합니다. 서명되지 않아 SmartScreen이 뜰 수 있습니다. EXE만 복사하지 마세요.

개인 목록·연결 정보·캐릭터 자료·위치는 로컬에 남으며 배포에 넣지 않습니다. 신규 설정은 영어·감시 OFF·미리보기 ON·사이트 제어 OFF·고정 OFF입니다. 기존 사용자 설정은 유지합니다. 미리보기로 시작해 허용 목록을 완성·검증한 뒤 실제 닫기를 켜세요. 저장하지 않은 작업이 손실될 수 있습니다.

소스 검증에는 Python 211개·확장 19개, 영어/한국어·테마·창 크기별 화면 8개와 연결된 모니터 3개(100%/125% 배율)의 합성 Qt 드래그 검사가 포함됩니다. 사용자도 기능 확인을 보고했으나 항목별 검사 보고는 아닙니다. 배포 검사는 최종 EXE의 내장 소스/버전·실행/렌더링·기본 설정·고지/개인정보 제외·ZIP 목록과 체크섬을 확인하며 Windows CI는 Python 3.12/3.14/3.15를 다룹니다. 모든 환경에서의 실제 손 드래그, 새 Windows 11 GPU/모델 검사나 개인 브라우저 프로필 전체 E2E를 주장하지 않습니다. 선택형 3D는 계속 실험 기능입니다.
